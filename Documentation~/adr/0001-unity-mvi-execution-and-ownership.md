# 保留 Unity MVI 的现有入口，集中执行与所有权知识

2026-10-01，按架构审核建议执行。保留 R3 的并发策略、Store 的同步状态提交以及 UGUI/FairyGUI 两套适配实现；Intent 执行链收拢为 Store 的私有实现，泛型 ViewModel 从基类唯一 Store 推导强类型视图，组件路由由 Runtime 派发一次。这样不增加调用者需要配置的新执行模型，也避免绑定、派发和释放规则分别留在多个调用位置。

同步入口遇到未完成的异步错误决策时不等待，保留捕获的上下文继续交付；同步完成的 Rethrow 仍抛回原调用栈，延迟 Rethrow 交付 R3 未处理错误通道。已有 Replay 的直接 Reducer 错误会等待相同内部 completion；同步持久化回调不冒充可等待的事务，不新增无法保证完整性的 UpdateStateAsync。

根视图在取得时记录创建或借用关系，之后配置变化不改变所有权。恢复配置未就绪不等于数据损坏：类型或迁移准备好前保留已有快照，避免 Store 初始化的 Save 随后覆盖合法数据；显式 Clear 或成功恢复后解除该保护。
